## 🐛 Common Issues & Fixes

### "Archive button is grayed out"
→ Select "Any iOS Device" (not simulator)

### "Bundle ID is taken"
→ Change to: com.YOURNAME.habittracker

### "Build not showing in App Store Connect"
→ Wait 10-30 minutes for processing

### "App rejected - no privacy policy"
→ Host privacy-policy.html and add URL

### "Can't sign app"
→ Check Apple Developer account is active

### "App crashes on launch"
→ Test on real device before submitting
